Why this can win
Most teams will show:
Plain Text
PR
→ Review
→ Code Fix
→ Merge
You've already noticed that from the examples.
Your project shows:
Plain Text
Enterprise Service Desk
+
Identity Governance
+
Incident Management
+
Approvals
+
Privilege Separation
+
Automatic RCA
The strongest differentiator is permission-scoped agents:
Approval Agent cannot modify systems.
Diagnostics Agent cannot grant access.
Identity Agent cannot restart Jenkins.
Execution Agent cannot approve changes.
That separation of duties makes it feel like a real ITSM platform rather than a collection of chatbots, and that's exactly the kind of architecture that stands out in a Switch-based hackathon.
